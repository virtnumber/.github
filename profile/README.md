# Virtnumber

Virtnumber rents dedicated virtual phone numbers in 14 countries, one number to one customer. All numbers receive SMS. Two-way numbers in the US and Sweden can also send, from the panel or over the API.

| Repository | What it is |
|---|---|
| [virtnumber-js](https://github.com/virtnumber/virtnumber-js) | JavaScript and TypeScript SDK for the REST API: `npm install virtnumber` |
| [mcp](https://github.com/virtnumber/mcp) | Connect the Virtnumber MCP server to Claude, Claude Code, Cursor, VS Code and other AI agents |
| [skills](https://github.com/virtnumber/skills) | Agent Skills for receiving and sending SMS from AI agents |

- Website: [virtnumber.com](https://www.virtnumber.com)
- Free temporary phone numbers to receive SMS online: [virtnumber.com/freesmsreceive](https://www.virtnumber.com/freesmsreceive)
- API and MCP reference: [virtnumber.com/developer](https://www.virtnumber.com/developer)
- Support: support@virtnumber.com
